# Praktikum Enkripsi dan Dekripsi

## Tujuan

Mahasiswa dapat melakukan:

1. Enkripsi data menggunakan Python.
2. Dekripsi data menggunakan key.
3. Membandingkan hasil enkripsi dan dekripsi.
4. Menguji penggunaan key yang berbeda.

## Persiapan

Pastikan Python sudah terinstall.

Install library:

```bash
pip install -r requirements.txt
```

## Menjalankan Program

Jalankan perintah:

```bash
python uji_enkripsi.py
```

## Pengujian

### Pengujian 1

Gunakan data:

```text
Nilai mahasiswa: 90
```

Amati:

```text
Data Asli
   ↓
Enkripsi
   ↓
Ciphertext
   ↓
Dekripsi
   ↓
Data Asli
```

### Pengujian 2

Gunakan data:

```text
Nama: Budi
NIM: 231001
```

Lakukan proses:

```text
Enkripsi → Dekripsi
```

### Pengujian 3

Gunakan key yang berbeda untuk proses dekripsi.

Amati apa yang terjadi.

## Pertanyaan

1. Apa perbedaan data asli dan ciphertext?
2. Apakah hasil dekripsi sama dengan data asli?
3. Apa yang terjadi jika key dekripsi berbeda?
4. Mengapa key harus dijaga?
